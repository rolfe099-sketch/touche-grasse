# Roadmap

The focus is fast, trustworthy logging. This list is direction, not a release promise.

1. Validate physical iPhones: keyboard, safe areas, storage, speech permissions, camera and sharing.
2. Expand Norwegian packaged-product coverage and add reviewed label OCR. Remote barcode lookup, source/license provenance, package review and saved-product caching are implemented; camera-to-review works on the owner's iPhone; permission/interruption checks remain.
3. Improve English/Norwegian ingredient coverage with explicit preparation and product ambiguity.
   Repeat eating now supports inline quantity adjustments, a separate retained repeat draft and explicit yesterday-meal commands. Named/pinned shortcuts remain future work.
4. Strengthen accessibility, backup portability and upgrade testing. Automatic local recovery copies are implemented; creating/exporting a copy to Files works on the owner's iPhone; native recovery merge remains pending. Optional cloud sync requires a separate design.
5. Investigate optional body-weight trends and useful target feedback without guessing missing intake.
6. Prepare signed releases and install/update instructions after native validation.

Contributions should preserve offline core functionality, privacy, verified nutrition and one-action logging. Cloud synchronization and new remote services need a design discussion.
