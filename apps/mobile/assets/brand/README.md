# Buy Me a Coffee

The cup logo is the original SVG from https://cdn.buymeacoffee.com/buttons/bmc-new-btn-logo.svg, fetched 3 November 2026 for the owner's support link. Brand resources: https://buymeacoffee.com/brand.

`src/ui/coffeeLogo.ts` embeds the same SVG for React Native SVG rendering. No remote widget or tracking script is loaded. The logo opens only https://buymeacoffee.com/endoftheend.
