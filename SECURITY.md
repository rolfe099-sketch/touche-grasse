# Security

This is an early development application. There is no hosted account or synchronization backend in this repository.

Report vulnerabilities through [GitHub's private vulnerability reporting](https://github.com/rolfe099-sketch/touche-grasse/security/advisories/new). If private reporting is unavailable, open a minimal issue asking for a private reporting channel, without exploit details or personal information. No response-time guarantee is offered.

Never publish tokens, signing keys, personal backups, diary history, recipe photos or recordings. Backup files are unencrypted and may contain sensitive information. Browser origin and OS storage protection apply; the app does not provide encrypted backups.

Dependency advisories change. Review `npm audit` with the pinned Expo SDK in mind. Do not apply forced upgrades without checking native compatibility and rerunning storage, nutrition and browser tests.
